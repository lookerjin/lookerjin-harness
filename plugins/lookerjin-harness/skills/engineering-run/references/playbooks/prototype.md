# Prototype

状态：Decision → Variants → Observe → Choose / Discard。

1. 定义实验要决定的具体问题、预算与观察指标。没有待决定的问题就按 Feature 推进。
2. 在隔离临时目录用最轻实现探索有结构差异的方案。必要时用 Design Explore；方向已定的单方案探针不强制增加候选。
3. 观察正在决定的行为：交互从真实 UI 驱动，时延与输出从实际运行采集。先检查输入数据、运行次数与外部依赖是否足以支持比较。
4. 根据证据推荐选取、继续实验或放弃；说明不能由本次实验回答的部分。
5. 清理自己启动的资源，保留观察证据。真实实现重新按 Feature 执行验收与回归，不把实验代码默认升级为生产实现。

退出门槛：决策得到证据支持，或明确无法收敛。产出是决策和可检查的实验，不是生产就绪声明。
